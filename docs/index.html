각 CLI의 공식 인증 정보를 자동으로 연동하거나 앱 안에서 개별 로그인·로그아웃할 수 있습니다.

GPT CLI (OpenAI Codex)

5시간 · 주간 구독 한도

ChatGPT Plus / Pro / Team 구독의 Codex CLI 잔여 한도와 리셋 카운트다운을 조회합니다.

  • codex login 터미널 실행 지원
  • %USERPROFILE%\.codex\auth.json 자동 감지
  • WSL 경로 파일 선택 및 토큰 직접 입력
AGY CLI (Antigravity)

5시간 · 주간 통합 한도

Google Antigravity CLI(agy)의 AI Pro / Ultra 구독 한도를 5시간·주간으로 정리해 표시합니다.

  • agy 자동 감지 및 공식 원클릭 설치
  • Windows 자격 증명 관리자(gemini:antigravity) 연동
  • 마우스 오버 시 Gemini / 3P 세부 잔여량 확인
Claude CLI (Claude Code)

5시간 세션 · 7일 주간 한도

Claude Pro / Max 구독의 세션·주간 잔여량과 추가 사용량 상태를 실시간 추적합니다.

  • claude auth login 터미널 실행 지원
  • .claude\.credentials.json 자동 감지
  • 만료 시 OAuth 토큰 자동 갱신 지원

왜 편한가요?

작업 흐름을 끊지 않도록 Windows 11에 맞춰 최대한 가볍고 직관적으로 설계했습니다.

여백 없는 초소형 플라이아웃 (`286px`)

트레이 아이콘을 클릭하면 작업 표시줄 바로 위에 내용 길이에 딱 맞는 미니 창이 열립니다. 로그인하지 않은 CLI는 남은 사용량 영역을 숨겨 화면을 깔끔하게 유지합니다.

남은 사용량(잔여 %) 직관 시각화

그래프 막대, 숫자 %, 트레이 아이콘 높이, 마우스 오버 툴팁 모두 남은 사용량 기준으로 통일했습니다. 잔여 35% 이하는 주황, 15% 이하는 빨강으로 경고합니다.

안정적인 Windows 11 트레이 아이콘

다중 해상도(16·32·48px) 실제 .ico와 고정 Windows GUID를 사용해 트레이 아이콘이 사라지지 않으며, 우클릭 메뉴에서 앱 재시작·시작 시 자동 실행을 바로 제어합니다.

알림센터 경고 & 자동 새로고침

설정한 주기(1·3·5·15분)마다 백그라운드에서 한도를 갱신하고, 한도가 임계치에 도달하면 Windows 11 알림센터 토스트 알림으로 알려줍니다.

설치 및 실행 방법

Node.js(v20 이상)가 설치된 Windows 11 환경이면 1분 안에 바로 실행할 수 있습니다.

git clone https://github.com/john3smith/cli-usage-tracker.git
cd cli-usage-tracker
npm install
동작 실행 방법 설명
콘솔 창 없이 실행 (권장) start-tray.vbs 더블클릭 까만 터미널 창 없이 바로 트레이 아이콘으로 실행됩니다.
터미널 / 배치 실행 .\start-tray.bat 또는 npm start PowerShell / CMD에서 앱을 실행합니다.
단위 테스트 실행 npm test 3개 프로바이더 파서, 설정 저장소, .ico 생성기를 검증합니다.
트레이 조작 좌클릭 / 우클릭 좌클릭: 한도 창 열기·닫기 / 우클릭: 새로고침 · 시작 시 실행 · 앱 재시작 · 종료

보안 및 로컬 우선 원칙

모든 인증 정보와 한도 조회는 사용자 PC와 각 공식 API 서버 간에 직접 통신하며, 외부 중계 서버를 거치지 않습니다.

Windows DPAPI 로컬 암호화

앱에 직접 입력한 OAuth 토큰은 Electron safeStorage(Windows DPAPI)로 암호화되어 %APPDATA%\cli-usage-tracker에만 저장됩니다.

소스 폴더와 사용자 데이터 분리

프로젝트 폴더에는 실행 코드만 존재하며, 개인 계정·토큰·로그 파일은 절대 프로젝트 디렉터리에 기록되지 않습니다.
